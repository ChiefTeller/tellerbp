# TellerBP

TellerBP is the minimal bilingual website for Teller Books Publishing, the publishing home for books by Nadav Teller.

Production domain: https://www.tellerbp.co.il/

## Site Overview

The site is intentionally quiet, simple, and book-focused. It includes a Hebrew home page and an English home page, built around four reading journeys:

- The Personal Journey
- The Social Journey
- The Philosophy Journey
- The Global Journey

## Main Files

- `index.html` - Hebrew home page
- `en.html` - English home page
- `404.html` - custom not-found page
- `styles.css` - visual design and responsive layout
- `script.js` - subtle scroll, reveal, and back-to-top behavior
- `assets/` - TellerBP logo, favicon, cover, and door images
- `robots.txt` - crawler access rules
- `sitemap.xml` - sitemap for search engines
- `llms.txt` - AI-readable site summary and topic map
- `ai-index.json` - structured knowledge file for search and AI agents

## Search and AI

The site includes structured metadata for books, publishing, spiritual literature, Jewish literature, philosophy books, political science books, redemption themes, civilization theory, Tao books, and the author Nadav Teller.

The AI and search files are intended to help search engines, language models, and agents understand the site accurately while keeping the public pages minimal.

## Local Preview

This is a static website. To preview it locally, open `index.html` in a browser or serve the folder with any simple static-file server.
